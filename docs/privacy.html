Privacy Policy

Last updated: October 30, 2026

Summary

Mangago Reading List Tracker runs entirely in your browser. It reads manga details from mangago.me pages you visit and writes them to a Google Sheet it creates for you. It has no server of its own and does not collect, sell or share your data.

Google user data we access

The extension asks for one Google permission: https://www.googleapis.com/auth/drive.file (see, edit, create and delete only the specific Google Drive files you use with this app). It cannot see any file it did not create. It uses this permission only to:

  • Create one spreadsheet named "Mangago Reading List" in your Google Drive.
  • List the spreadsheets it created for you before (name and last-changed date), so you can keep using one after reinstalling.
  • Read that spreadsheet's title, to confirm the connection works.
  • Read the first column of Sheet1 in that spreadsheet, to find rows that already exist.
  • Write rows containing a manga's title, reading status, last chapter and page URL to that spreadsheet.

It does not open, read or change any other spreadsheet, and it does not access your email, contacts, other Drive files or any other Google data.

Data stored on your device

  • The ID of the spreadsheet the extension created, saved with Chrome's built-in extension storage so it syncs between your own Chrome browsers.
  • A Google access token, managed by Chrome itself and kept only in memory by the extension.

Sharing

Data goes directly from your browser to Google's Sheets API. The developer never receives it. Nothing is sent to any other party, and the extension contains no analytics, ads or tracking.

Limited Use

Mangago Reading List Tracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

  • Revoke the extension's Google access at myaccount.google.com/permissions.
  • Uninstall the extension from chrome://extensions to delete its stored settings.
  • Rows already written to your spreadsheet stay there until you delete them, because the sheet belongs to you.
