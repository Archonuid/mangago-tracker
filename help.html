Setup Guide

  1. Create a new Google Sheet at sheets.new. Leave the first tab named Sheet1.
  2. Copy the spreadsheet ID from the address bar. It's the long part between /d/ and /edit:
    docs.google.com/spreadsheets/d/THIS_PART/edit
  3. Click the Mangago Tracker icon in Chrome's toolbar, paste the ID, and click Save Settings.
  4. Click Test Connection. A Google sign-in window opens. Choose the account that owns the sheet and allow access to Google Sheets.
  5. When you see Connected to "your sheet name", you're done. Open a manga on mangago.me and click Want to Read, Reading or Completed. The sheet updates automatically.

Troubleshooting

"OAuth2 request failed … bad client id"

Google didn't recognize this copy of the extension. This happened with version 1.0.0 when it was installed from the downloaded files. To fix it:

  1. Go to chrome://extensions and remove Mangago Tracker.
  2. Download the latest version from github.com/Archonuid/mangago-tracker (Code → Download ZIP), unzip it, and load it again with Load unpacked.
  3. Check that the Extension ID at the top of this page is gpojgbkdeecfajdfnjllinahgaphpmki. If it is different, you have an old copy.

If the ID matches and you still see this error, contact the developer and include the extension ID shown above.

"Access blocked" or "This app is blocked" on the Google sign-in screen

The app is still in Google's testing mode, so only approved accounts can sign in. Ask the developer to add your Google account as a tester.

"Google hasn't verified this app"

This is expected for small independent extensions. Click Advanced → Go to Mangago Reading List Tracker to continue. The extension can only reach Google Sheets. It can't see your email or other files.

"Spreadsheet not found"

The ID is wrong or incomplete. Copy it again from the sheet's address bar (only the part between /d/ and /edit) and save.

"Permission denied"

You signed in with a Google account that can't edit this sheet. Share the sheet with that account, or create the sheet with the same account you signed in with.

"Spreadsheet ID not configured"

Paste your spreadsheet ID in the popup and click Save Settings before testing.

Clicks on Mangago don't show up in the sheet

  • Run Test Connection first. Syncing only works after you're connected.
  • Reload the Mangago tab after installing or updating the extension.
  • Make sure the sheet still has a tab named Sheet1.

Signed in with the wrong Google account

Go to myaccount.google.com/permissions, remove Mangago Reading List Tracker, then click Test Connection again.
