Setup Guide

  1. Click the Mangago Tracker icon in Chrome's toolbar.
  2. Click Set up my tracking sheet. A Google sign-in window opens. Choose your Google account and allow access.
  3. If the extension made a sheet for you before, it lists it. Click it to keep using it, or click Create a new sheet instead. Otherwise it creates a sheet called Mangago Reading List in your Google Drive straight away.
  4. Click Open my sheet to see it.
  5. Open a manga on mangago.me and click Want to read, Now reading or Already read. The sheet updates automatically.

The extension can only see sheets it created. It can't open any of your other files.

Using Brave, Edge or Opera

Install from the same Chrome Web Store page. In these browsers, Google sign-in opens in its own window instead of using a Chrome account. Google's sign-in lasts an hour; the extension renews it quietly, but you may occasionally see the sign-in window again.

Brave only: go to brave://settings/extensions and turn on Allow Google login for extensions before clicking Set up my tracking sheet.

Troubleshooting

"OAuth2 request failed … bad client id"

Google didn't recognize this copy of the extension. This was fixed on Google's side in October 2026, so try again first.

If it still happens, remove the extension in chrome://extensions and add it again from the Chrome Web Store. The Extension ID at the top of this page should then be hekjmppkcgbfenheehhhiibdajdpaigi.

Still stuck? Contact the developer and include the extension ID shown above.

"Can't open this sheet. The extension can only use sheets it created."

Since version 1.1, the extension only has access to sheets it made itself. A sheet you created by hand, or one you used with version 1.0, won't work and won't show up in the list. Click Set up my tracking sheet to make a new one. You can copy your old rows into it.

If you see this for a sheet the extension did create, you're probably signed in with a different Google account. See Signed in with the wrong Google account below.

"Google sign-in didn't open" in Brave

Go to brave://settings/extensions, turn on Allow Google login for extensions, then try again.

"Access blocked" on the Google sign-in screen

Contact the developer and include the extension ID shown at the top of this page.

"Spreadsheet ID not configured"

Click Set up my tracking sheet in the popup first.

Reinstalled the extension, or using a new computer

If you're signed in to Chrome, your sheet is remembered automatically. If not, click Set up my tracking sheet and sign in with the same Google account. Your earlier sheet will be listed, and you can click it to keep using it.

Clicks on Mangago don't show up in the sheet

  • Create your sheet from the popup first, then click Test Connection to check it.
  • Reload the Mangago tab after installing or updating the extension.
  • Make sure the sheet still has a tab named Sheet1.

Signed in with the wrong Google account

Go to myaccount.google.com/permissions, remove Mangago Reading List Tracker, then click Test Connection again and pick the right account.
