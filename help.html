Setup Guide

  1. Click the Mangago Tracker icon in Chrome's toolbar.
  2. Click Create my tracking sheet. A Google sign-in window opens. Choose your Google account and allow access.
  3. The extension creates a sheet called Mangago Reading List in your Google Drive. Click Open my sheet to see it.
  4. Open a manga on mangago.me and click Want to Read, Reading or Completed. The sheet updates automatically.

The extension can only see sheets it created. It can't open any of your other files.

Troubleshooting

"OAuth2 request failed … bad client id"

Google didn't recognize this copy of the extension. This happened with version 1.0.0 when it was installed from the downloaded files. To fix it:

  1. Go to chrome://extensions and remove Mangago Tracker.
  2. Download the latest version from github.com/Archonuid/mangago-tracker (Code → Download ZIP), unzip it, and load it again with Load unpacked.
  3. Check that the Extension ID at the top of this page is gpojgbkdeecfajdfnjllinahgaphpmki. If it is different, you have an old copy.

If the ID matches and you still see this error, contact the developer and include the extension ID shown above.

"Can't open this sheet. The extension can only use sheets it created."

Since version 1.1, the extension only has access to sheets it made itself. A sheet you created by hand, or one from an older version, won't work. Click Create my tracking sheet to make a new one. You can copy your old rows into it.

If you see this for a sheet the extension did create, you're probably signed in with a different Google account. See Signed in with the wrong Google account below.

"Access blocked" on the Google sign-in screen

Contact the developer and include the extension ID shown at the top of this page.

"Spreadsheet ID not configured"

Click Create my tracking sheet in the popup first.

Reinstalled the extension, or using a new computer

If you're signed in to Chrome, your sheet is remembered automatically. If not, open Use a sheet ID instead in the popup and paste the ID of the sheet the extension created before. It's the part of the sheet's address between /d/ and /edit.

Clicks on Mangago don't show up in the sheet

  • Create your sheet from the popup first, then click Test Connection to check it.
  • Reload the Mangago tab after installing or updating the extension.
  • Make sure the sheet still has a tab named Sheet1.

Signed in with the wrong Google account

Go to myaccount.google.com/permissions, remove Mangago Reading List Tracker, then click Test Connection again and pick the right account.
